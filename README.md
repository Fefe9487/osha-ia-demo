# 職安署改造後架構｜展示假站

非正式網站。給簡報與跨組討論用，示範改造後的前台選單與搬家關係。不是勞動部職業安全衛生署官網，也不接後台。

線上展示（GitHub Pages）：<https://fefe9487.github.io/osha-ia-demo/>

## 本機預覽

雙擊 `index.html` 即可。若瀏覽器擋本地腳本，在本資料夾執行：

```
python -m http.server 8765
```

再開 <http://127.0.0.1:8765/>。

## 簡報三條

1. 便民服務 → 只剩動詞入口
2. 過勞專區／我沒加保／事業單位職災通報 → 制度回專業區
3. 新聞公告 → 只看訊息

頁面上的新聞標題與日期是展示用假資料，請勿轉載為署方公告。
